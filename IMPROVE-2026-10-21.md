## APK history purge (exact steps)

```bash
git clone --mirror git@github.com:SIP-01/Crawlstr-SIP-Relay.git
git filter-repo --path app/release --invert-paths   # drops APKs, .dm, output-metadata.json
git push --force --all && git push --force --tags
```
Then add `app/release/` (or `*.apk`) to `.gitignore` so CI-built APKs never return; attach release APKs via GitHub Releases (`.github/workflows/create-release.yml` already exists — wire artifacts there). Warn: force-push breaks open clones; the ~17 stale `claude/*` and `pr/*` branches should be deleted in the same maintenance window.
