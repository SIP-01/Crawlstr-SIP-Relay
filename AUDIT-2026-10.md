# Security Audit — SIP-01/Crawlstr-SIP-Relay — 2026-10-20

## Summary
Kotlin/Android Nostr relay (fork of greenart7c3/Citrine) extended into a mobile SIP-01 indexing relay: §12.4 ingestion validation for kind 39697, byte-compatible normalization verified against spec §13 test vectors, NIP-50 operators, optional federation sync with WiFi-only/limited-network pausing. The SIP-01 additions look careful. **The problem is freshness: the fork is based on Citrine 3.0.1 (versionCode 61, 2026-06-19) while upstream is at v3.2.0 (2026-09-18) — and upstream v3.1.1 (2026-09-11) fixed a genuine NIP-42 AUTH bypass that this fork still carries.** No committed keystores or secrets found. Findings: 0 CRITICAL / 1 HIGH / 0 MEDIUM / 3 LOW.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| CSR-H1 | HIGH | whole tree (Citrine 3.0.1 base) | Missing upstream security fix — Citrine v3.1.1: "Fixed an NIP-42 auth bypass where kind-22242 AUTH events were added to the connection without signature verification", plus per-connection REQ subscription-id scoping (cross-socket subscription clobbering) and NIP-42 access-control fixes. A relay that authenticates connections without verifying the AUTH event signature accepts forged identities. Also missing v3.2.0 OOM fixes (unbounded REQ result materialization; capped relay-aggregator memory) — stability/DoS relevant on a phone relay. | Rebase/merge upstream v3.1.1 + v3.2.0 (or cherry-pick the AUTH-verification and subscription-scoping commits), then re-apply the SIP-01 layer; add a regression test for AUTH signature verification. |
| CSR-L1 | LOW | app/release/ | Five built APKs (~60 MB) committed to git (`app-universal-release.apk` etc.). Bloat + supply-chain ambiguity: unsigned/unknown-provenance binaries in the repo that users might sideload. | Remove binaries; attach APKs to GitHub Releases with hashes (upstream's GPG-signed manifest pattern). |
| CSR-L2 | LOW | .idea/ (tracked) | IDE config directory committed (upstream removed it 2026-09-18; the fork still carries it). May leak local paths/settings. | Untrack `.idea/` and extend .gitignore (upstream's fix is a clean cherry-pick). |
| CSR-L3 | LOW | .gitignore | Keystore ignores (`*.jks`, `*.keystore`) are commented out; `keystore.properties` is ignored (good) but a stray keystore file could be committed unnoticed. Signing is env-gated (`SIGN_RELEASE`) with secrets loaded from untracked `keystore.properties` — design is fine, guardrail is off. | Uncomment the keystore ignore lines. |

## Fork/Upstream Freshness

Upstream HEAD: v3.2.0 (2026-09-18). **The fork is ~3 months / 3 releases behind (3.1.0, 3.1.1, 3.2.0) and missing a confirmed upstream security fix (NIP-42 auth bypass, v3.1.1) plus OOM/DoS-relevant fixes (v3.2.0).**
